# Análise Comercial com MySQL

Projeto desenvolvido para praticar criação, organização e análise de dados utilizando MySQL.

O sistema representa um pequeno banco de dados comercial, contendo informações sobre clientes, produtos e vendas.

# Objetivo

O objetivo do projeto é utilizar um banco de dados relacional para armazenar informações comerciais e realizar consultas que permitam analisar os dados das vendas.

O projeto foi desenvolvido com foco no aprendizado de SQL e na aplicação prática de conceitos de banco de dados.
